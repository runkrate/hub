# KRATE Hub

Single entry point for **bug reports**, **feature requests**, and **planning** across the whole KRATE project.

Issues are triaged here and tracked on the org [GitHub Project](https://github.com/orgs/krate-client/projects) — not in individual component repositories.

## Before opening an issue

1. Check [existing issues](https://github.com/krate-client/hub/issues) and the project board.
2. Read the [documentation](https://krate.github.io/docs/) for setup and usage questions.
3. Pick the right template below (bug vs feature vs question).

## What goes here

| Use Hub for | Use elsewhere |
|---|---|
| Bugs in KRATE, zen, HarmonyUI, setup, releases | **Pull requests** in the relevant repo (`console`, `web`, …) |
| Feature ideas and roadmap discussion | **App changes** → PR on [`apps-official-source`](https://github.com/krate-client/apps-official-source) or [`apps-community`](https://github.com/krate-client/apps-community) |
| Installation or upgrade problems | **Docs fixes** → PR on [`docs`](https://github.com/krate-client/docs) |
