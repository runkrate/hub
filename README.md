# KRATE Hub

Single entry point for **bug reports**, **feature requests**, and **planning** across the whole KRATE project.

Issues are triaged here and tracked on the org [GitHub Project](https://github.com/orgs/runkrate/projects) — not in individual component repositories.

## Before opening an issue

1. Check [existing issues](https://github.com/runkrate/hub/issues) and the project board.
2. Read the [documentation](https://github.com/runkrate/docs) for setup and usage questions.
3. Pick the right template below (bug vs feature vs question).

## What goes here

| Use Hub for | Use elsewhere |
|---|---|
| Bugs in KRATE, zen, HarmonyUI, setup, releases | **Pull requests** in the relevant repo (`console`, `web`, …) |
| Feature ideas and roadmap discussion | **App changes** → PR on [`krate-apps/sources`](https://github.com/krate-apps/sources) or [`krate-apps/community`](https://github.com/krate-apps/community) |
| Installation or upgrade problems | **Docs fixes** → PR on [`docs`](https://github.com/runkrate/docs) |

## Component repositories

| Area | Repository |
|---|---|
| CLI & core engine | [console](https://github.com/runkrate/console) |
| Web dashboard | [web](https://github.com/runkrate/web) |
| First-boot setup | [setup](https://github.com/runkrate/setup) |
| Official apps (authoring) | [krate-apps/sources](https://github.com/krate-apps/sources) |
| Official apps (mirror) | [krate-apps/core](https://github.com/krate-apps/core) |
| Community apps | [krate-apps/community](https://github.com/krate-apps/community) |
| Extensions & themes | [krate-apps/extensions](https://github.com/krate-apps/extensions) |
| Documentation | [docs](https://github.com/runkrate/docs) |
| Packages & updates | [krate](https://github.com/runkrate/krate) |
| GitHub → Discord | [sentinel](https://github.com/runkrate/sentinel) |
